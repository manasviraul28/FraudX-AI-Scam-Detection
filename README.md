FraudX: AI-Powered Scam DetectionThis is a mobile application developed to protect users from fraud calls, phishing and SMS fraud.  
Key Features:
* On-Device ML: Uses an optimized TFLite model to ensure privacy and low battery usage.
* High-Visibility UI: Designed specifically to make technical security alerts easy for everyone to understand.
* Tech Stack:* Language: Kotlin * Model: TensorFlow Lite * Database: Room
